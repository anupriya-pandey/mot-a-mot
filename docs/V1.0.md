# Mot-à-Mot V1.0 — Iteration Snapshot

**Release date:** July 2026  
**Git tag:** `v1.0.0`  
**Package version:** `1.0.0`

## Purpose

Mot-à-Mot helps beginner French learners (A1–B1) verify, improve, and confidently send everyday French messages before pressing Send.

## V1.0 scope — what's included

### Application code

- **Frontend:** React 18, TypeScript, Vite 6, Tailwind CSS
- **Backend:** Express API on port 3001, proxied via Vite in dev
- **AI providers:** Gemini (default free), Ollama (local free), OpenAI (paid)

### User flows

1. **Landing** — type or speak a French sentence, submit for analysis
2. **Loading** — animated wait while AI processes
3. **Results** — structured feedback screen (see layout below)

### Results screen layout (V1.0)

1. **Your Sentence** — original user input
2. **What I Understood**
   - Literal word-for-word English
   - In everyday French — conversational usage
3. **Ready to Send** — corrected natural French + copy button
4. **Comparison table** — you wrote / better French / why
5. **Why These Changes?** — educational grammar notes (3–5 lines)
6. **Your Sentence Scores** — grammar & naturalness % for the **original** sentence

### Voice input (V1.0)

- Web Speech API, `fr-FR`
- Chrome/Edge recommended
- Microphone permission flow with clear error messages
- Live interim transcript while listening

### AI prompting (V1.0)

Full prompt and JSON schema documented in [PROMPTS.md](./PROMPTS.md).

Key prompt decisions:
- Literal + everyday meaning split (`understood` + `everydayMeaning`)
- Educational `grammarNotes` — teach underlying rules, not "because French"
- Ratings always score the **original** user sentence
- Structured JSON output for reliable UI rendering

### Dev tooling

- `start-dev.cmd` — Windows launcher, kills stale processes on ports 3001/5173
- `.env.example` — template for all provider options

### Design & product documentation

- [docs/design/](./design/) — PRD, UX spec, UI style guide, component library
- Original PDFs preserved in `docs/design/originals/`
- V1.0 implementation deltas in `docs/design/V1.0-IMPLEMENTATION-NOTES.md`

## Out of scope for V1.0

- User accounts / persistence
- Production deployment config
- Mobile native apps
- Offline mode (except via Ollama)
