# V1.0 Implementation Notes — Design Spec Deltas

This document records intentional differences between the **original V1 design specs** and the **shipped V1.0 codebase**.

## Results screen order (updated in V1.0)

| Original spec | V1.0 implementation |
|---------------|---------------------|
| What I Understood → Ready to Send → Copy → Changes → Why → Ratings | **Your Sentence** → What I Understood → Ready to Send → Copy → Changes → Why → **Your Sentence Scores** → Check Another |

### Rationale

- **Your Sentence** — user requested side-by-side comparison with correction
- **What I Understood** — split into *Literal* + *In everyday French* (V1.0 enhancement)
- **Your Sentence Scores** — explicit heading clarifying ratings apply to original input, not AI correction
- **Check Another Sentence** — moved below ratings for better flow after review

## AI response fields (V1.0)

| Original PRD | V1.0 |
|--------------|------|
| What I Understood (single) | `understood` + `everydayMeaning` |
| Grammar notes 2–3 lines | 3–5 lines, more educational rationale |
| Ratings (original sentence) | Same — now labeled in UI |

See [../PROMPTS.md](../PROMPTS.md) for current AI prompt.

## Voice input (V1.0)

Beyond original spec:

- Explicit microphone permission flow
- Browser-specific error messages
- Live interim transcript while listening
- Chrome/Edge recommended

## AI providers (V1.0)

Not in original PRD — added for accessibility:

- Gemini (free tier, default)
- Ollama (local free)
- OpenAI (paid)

## Landing screen

- Empty input shows inline warning banner (orange) per UX error spec
- Ctrl/Cmd+Enter submits from textarea
